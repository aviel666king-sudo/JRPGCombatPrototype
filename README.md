# JRPG Combat Prototype

Turn-based JRPG combat system prototype in Unreal Engine 5.

## Features Implemented
- Turn based combat system
- Combatants (Player / Enemy)
- Status effects (Burn, Fragile)
- Skill system
- AP system
- UI Combat HUD
- Minigame infrastructure

## Planned Features
- Parry system
- Reactive abilities
- Party combat (3 vs 3)
- AI improvements
- More minigames

## Engine
Unreal Engine 5

## Status
Early Prototype
